# Project Manager

Este projeto é um desafio para recriar três páginas (Home, Login e Kanban) de uma ferramenta de produtividade, utilizando apenas HTML, CSS e JavaScript, seguindo o design original. O objetivo é desenvolver uma interface funcional com validação de formulários, redirecionamento de páginas e armazenamento de dados no LocalStorage.

## Descrição do Desafio

Você precisará recriar as três páginas mencionadas acima, mantendo-se fiel ao seu design original, utilizando HTML, CSS e JavaScript. 

⚠️ **Data de entrega**: 14/10 – 17h30 – segunda-feira.

Cada apresentação durará no máximo 5 minutos.

### 📍Descrição Header e Footer:
- **Header**: presente em todas as páginas, com botões que redirecionam para as respectivas páginas.
- **Footer**: deve estar em todas as páginas, com ícones de redes sociais clicáveis.

### Requisitos **OBRIGATÓRIOS**:
- Utilizar apenas HTML, CSS e JS, sem bibliotecas externas.
- Repositório privado no GitHub.
- Validação de formulários com JavaScript.
- Separar código em arquivos `.html`, `.css`, e `.js`.
- Tags semânticas no HTML.
- Pequenos commits com Conventional Commits.

### Páginas:
- **Home**: validação de e-mail e nome, armazenamento no LocalStorage.
- **Login**: validação de e-mail e senha, redirecionamento ao Kanban.
- **Kanban**: três colunas ("To Do", "In Progress", "Complete"), design fiel ao Figma.

### Requisitos **OPCIONAIS**:
- Responsividade.
- Efeitos de Hover.
- Mensagem de confirmação ao enviar dados corretamente.
